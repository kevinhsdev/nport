# Product

## Platform

web

## Stack

Next.js (App Router, TypeScript) with `output: "export"`, Tailwind CSS v4, GSAP + ScrollTrigger, Lenis, Motion, Lucide, Devicon. Deployed to GitHub Pages (`nathalialemesg.github.io/portifolio`) through GitHub Actions. Chosen by the user.

## Users

Tech recruiters and engineering interviewers screening internship (estágio) candidates in TI. They skim in seconds, filter by semester, graduation date, availability and English, and want a direct contact channel.

## Product Purpose

Personal portfolio of Nathalia Lemes Gonçalves, Software Engineering student, to win an internship interview. Success: a recruiter understands who she is, sees proof of working software, and emails her.

## Positioning

Every project is playable in the browser: four working academic systems (CareDrop, Controle de Diabetes, NeoLogix, NINA Tecnologia) with persistence, validation and CSV export. Proof by demonstration, not screenshots.

## Capabilities and Constraints

- Static site only (GitHub Pages). Demo data lives in `localStorage` under key `nathalia_portfolio_v3`; existing visitor data must keep loading.
- Demos use fictitious data only and must keep the disclaimers (no medical evaluation; conceptual network diagram).
- Content language: Brazilian Portuguese.
