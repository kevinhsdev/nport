# Portfólio · Nathalia Lemes

Portfólio de Nathalia Lemes, estudante de Engenharia de Software (UMC). Quatro sistemas acadêmicos que rodam no navegador: CareDrop, Controle de Diabetes, NeoLogix e NINA Tecnologia.

Next.js (export estático) · Tailwind CSS v4 · GSAP ScrollTrigger · Lenis · Motion · shader WebGL na hero.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # gera ./out
```

Deploy: `.github/workflows/deploy.yml` publica no GitHub Pages a cada push na `main` (Settings → Pages → Source: GitHub Actions).

Conteúdo editável em `src/lib/content.ts` (preencha `role` e `repo` de cada projeto).
